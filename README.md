# Face Mask Detection using Transfer Learning

## Project Description

A real-time face mask detection system using transfer learning with
MobileNetV2 and OpenCV.

## Technologies

- Python
- TensorFlow
- Keras
- MobileNetV2
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Pipeline

Dataset
→ Preprocessing
→ MobileNetV2
→ Transfer Learning
→ Mask/No Mask Classification
→ OpenCV Webcam
